# CVERecon-Rust

A Rust-based reconnaissance tool that collects detailed information about a given target (IP or URL).  
It performs DNS resolution, reverse lookup, scrapes Shodan public pages (no API needed), extracts open ports, CVEs, and identifies technologies used by the host. (yes the readme is generated by AI)

---

## ✨ Features

- DNS resolution and reverse DNS lookup  
- Public Shodan HTML scraping to extract:
  - Open ports  
  - CVEs  
  - Technologies  
- Technology detection via HTML, headers, and local `apps.json` database  
- Clean and dynamic terminal output using PrettyTable  
- Works on Linux, Windows, and macOS  
- Automatically adapts to terminal width  

---

## 📦 Installation

### 1. Clone the repository
```bash
git clone https://github.com/zt3x2b/CVERecon-Rust.git
cd CVERecon-Rust
````

### 2. Build the project

```bash
cargo build --release
```

### 3. (Optional) Add Wappalyzer-style tech detection database

If you want extended technology detection, place an `apps.json` file in the project root:

```
apps.json
src/
Cargo.toml
```

---

## ▶️ Usage

Run directly with Cargo:

```bash
cargo run --release
```

Or via the compiled binary:

```bash
./target/release/cverecon-rust
```

Enter an IP or URL when prompted:

```
Enter a target (IP or URL):
```

Type `exit` to quit.

## 🔧 Main Dependencies

* reqwest — async HTTP client
* tokio — async runtime
* scraper — HTML parsing
* regex — pattern extraction (ports, CVEs, etc.)
* prettytable — terminal table formatting
* colored — colorized terminal output
* trust-dns-resolver — DNS & reverse lookup
